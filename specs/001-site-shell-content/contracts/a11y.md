# Accessibility Contract (a11y)

Status: Draft v1 (2025-10-06)

Defines required accessibility semantics, keyboard interactions, and verification criteria for the Site Shell & Content Architecture feature.

## 1. Principles
- Meet WCAG 2.1 AA for pages in scope.
- No keyboard traps; all interactive controls reachable and operable via keyboard only.
- Provide skip navigation, semantic landmarks, and logical heading structure.

## 2. Landmarks & Structure
| Region | Element | Requirement |
|--------|---------|-------------|
| Skip Link | `<a href="#main" class="sr-only focus:not-sr-only">` | First focusable element in DOM order |
| Header | `<header role="banner">` | Contains site nav + theme toggle |
| Navigation | `<nav aria-label="Main">` | Provides section links (homepage grid is not nav) |
| Main | `<main id="main">` | Single per page; contains primary content |
| Footer | `<footer role="contentinfo">` | Site-level info |

## 3. Heading Hierarchy
| Page Type | H1 | H2 | Notes |
|-----------|----|----|------|
| Homepage | Site name / tagline | Section grid heading optional | Only one H1 |
| Section Listing | Section name | Filters heading (optional) | Articles use semantic list `<ul>` |
| Article | Article title | Content sub-sections from markdown | Ensure markdown starts with h2/h3 not h1 |
| Not Found | Descriptive error message | Suggestions list heading | Provide context for screen readers |

Validation: e2e test asserts single H1, monotonic descending levels (no h4 without preceding h3 on same page).

## 4. Focus Management
| Scenario | Behavior |
|----------|----------|
| Page load | Focus stays on body; skip link available on Tab |
| Skip link activated | Moves focus to `<main>` heading or first h1/h2 | Prevent double tab stops |
| Theme toggle click | Focus remains on toggle (no forced blur) |
| Filter selection | Focus stays on filter control; results list updates with `aria-live="polite"` summary region |
| Not-found navigation link selection | Works via Enter/Space keys |

## 5. Keyboard Interaction
| Component | Keys | Behavior |
|----------|------|----------|
| Theme Toggle | Space/Enter | Toggles state; updates `aria-pressed` |
| Chain Filter (select) | Arrow Down/Up | Navigate options |
| Chain Filter | Enter/Space | Select highlighted option |
| Tag Filter (list or select) | Same as chain | Single selection only |
| Skip Link | Enter | Jumps to main |

## 6. ARIA & Attributes
| Element | Attribute | Purpose |
|---------|-----------|---------|
| Theme Toggle | `role="button" aria-pressed="true|false"` | Convey toggle state |
| Results Count Region | `aria-live="polite"` | Announce filter result changes |
| Filter Controls | `aria-label` | Provide descriptive label (e.g., "Select chain") |
| Invalid Filter Option (future) | `aria-disabled="true"` | If certain chain filtered out (deferred) |

## 7. Color & Contrast
- Minimum contrast: 4.5:1 for text, 3:1 for UI component boundaries.
- Ensure theme toggle and focus outlines meet contrast on both light & dark backgrounds.
- Avoid color-only differentiation for status (use icon shape or text).

## 8. Motion & Preferences
- Respect `prefers-reduced-motion: reduce`: disable transition animations for theme toggle and content fade-ins.
- Provide instant theme switch (no excessive animation) under reduced motion.

## 9. Error & Empty States
| State | Requirement |
|-------|-------------|
| Empty filter results | Provide text: "No results match this filter" and guidance to clear filters |
| Not-found page | Offer link to homepage and possibly a search suggestion (future) |

## 10. Testing Strategy
| Tool / Method | Scope |
|---------------|-------|
| Playwright e2e | Focus order, skip link, filters interaction |
| axe-core integration | Landmarks, headings, contrast (basic) |
| Manual audit | Color contrast for brand palette, reduced motion |

Test Seeds:
| Scenario | Test ID |
|----------|---------|
| Skip link focusable first | TID-A11Y-SKIP-FIRST |
| Single H1 enforcement | TID-A11Y-H1-UNIQUE |
| Theme toggle aria-pressed updates | TID-A11Y-THEME-PRESSED |
| Filter results live region announces changes | TID-A11Y-LIVE-REGION |
| Reduced motion disables transitions | TID-A11Y-REDUCED-MOTION |

## 11. Non-Goals (Deferred)
| Item | Reason |
|------|--------|
| High-contrast mode toggle | Extra design complexity |
| Screen reader specific shortcuts | Limited initial scope |
| Localization of ARIA labels | i18n deferred |

## 12. Risks & Mitigations
| Risk | Mitigation |
|------|-----------|
| Overuse of ARIA where native semantics suffice | Favor native elements first |
| Focus loss on SPA navigation | Ensure App Router sets correct focus target or manually manage |
| Live region spam on rapid filter changes | Debounce announcements (100–150ms) |
